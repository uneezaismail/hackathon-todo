## Overview

This document defines the API contracts for all services in Phase V. All APIs follow OpenAPI 3.0.3 specification and are automatically generated by FastAPI.

**Services**:
1. **Backend API** (FastAPI) - Task CRUD, User Management, JWT Validation
2. **Recurring Task API** - Recurring task management (via Dapr Service Invocation)
3. **Alert API** - Alert scheduling and management (via Dapr Service Invocation)
4. **Notification API** - Internal notification delivery (via Dapr Service Invocation)

**Authentication**:
- All public endpoints require Better Auth JWT token in `Authorization: Bearer <token>` header
- Internal service-to-service calls use Dapr Service Invocation with mTLS
- `user_id` extracted from JWT and propagated in all service calls

## Backend API Contracts

### Base URL
- Local: `http://localhost:8000`
- Minikube: `http://backend-service:8000`
- AKS: `https://api.hackathon-todo.com`

### Common Headers

```
Authorization: Bearer <jwt_token>
Content-Type: application/json
dapr-app-id: backend-service  (for Dapr Service Invocation)
```

### Common Response Codes

| Code | Description |
|------|-------------|
| 200 | Success |
| 201 | Created |
| 400 | Bad Request (validation error) |
| 401 | Unauthorized (missing/invalid JWT) |
| 403 | Forbidden (user_id mismatch) |
| 404 | Not Found |
| 422 | Unprocessable Entity (business logic error) |
| 500 | Internal Server Error |

### Task Endpoints

#### POST /api/v1/tasks - Create Task

**Description**: Create a new task with optional recurrence pattern and alert configuration.

**Request Body**:

```yaml
type: object
required: [title, user_id]
properties:
  title:
    type: string
    maxLength: 255
    description: Task title
  description:
    type: string
    nullable: true
    description: Detailed task description
  priority:
    type: string
    enum: [low, medium, high, urgent]
    default: medium
    description: Task priority
  due_date:
    type: string
    format: date-time
    nullable: true
    description: Task due date (ISO 8601, UTC)
  recurrence_pattern:
    type: string
    nullable: true
    enum: [DAILY, WEEKLY, MONTHLY, YEARLY, CUSTOM]
    description: Recurrence pattern type
  recurrence_rrule:
    type: string
    nullable: true
    description: RRULE expression for custom patterns (RFC 5545 simplified)
  recurrence_end_date:
    type: string
    format: date-time
    nullable: true
    description: Optional end date for recurrence
  recurrence_interval:
    type: integer
    minimum: 1
    nullable: true
    description: Interval for custom patterns (e.g., every 2 weeks)
  recurrence_byday:
    type: array
    items:
      type: string
      enum: [MO, TU, WE, TH, FR, SA, SU]
    nullable: true
    description: Days of week for custom patterns
  recurrence_byhour:
    type: array
    items:
      type: integer
      minimum: 0
      maximum: 23
    nullable: true
    description: Hours of day for custom patterns
  alerts:
    type: array
    items:
      type: object
      properties:
        alert_time:
          type: string
          format: date-time
          description: Alert time (ISO 8601, UTC)
        notification_channels:
          type: array
          items:
            type: string
            enum: [email, push]
          default: [email]
          description: Notification channels (email primary, push fallback)
    nullable: true
    description: Alert configurations
  tags:
    type: array
    items:
      type: string
    nullable: true
    description: Task tags
```

**Response 201**:

  due_date:

    format: date-time
    nullable: true
  completed_at:
    type: string
    format: date-time
    nullable: true
  created_at:
    type: string
    format: date-time
  updated_at:
    type: string
    format: date-time

    type: string
    nullable: true
  recurrence_end_date:
    type: string
    format: date-time
    nullable: true
  next_occurrence:
    type: string
    format: date-time

#### GET /api/v1/tasks - List Tasks

**Description**: Retrieve paginated list of tasks for authenticated user.

**Query Parameters**:

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| page | integer | 1 | Page number (1-indexed) |
| page_size | integer | 20 | Items per page (max 100) |
| status | string | all | Filter by status (pending, in_progress, completed) |
| priority | string | all | Filter by priority (low, medium, high, urgent) |
| due_date_from | date-time | null | Filter tasks due after this date |
| due_date_to | date-time | null | Filter tasks due before this date |
| search | string | null | Search in title and description |
| sort_by | string | created_at | Sort field (created_at, due_date, priority) |
| sort_order | string | desc | Sort direction (asc, desc) |

**Response 200**:

```yaml
type: object
properties:
  tasks:
    type: array
    items:
      $ref: '#/components/schemas/Task'
  pagination:
    type: object
    properties:
      page:
        type: integer
      page_size:
        type: integer
      total_items:
        type: integer
      total_pages:
        type: integer
      has_next:
        type: boolean
      has_previous:
        type: boolean
```
